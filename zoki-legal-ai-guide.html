ВОДИЛКА ЗА ЗОКИ · КАКО СЕ КОРИСТИ ПАКЕТОТ

Не барај алатка. Почни од задачата.

Оваа водилка го води Зоки по сценарио. Секој пат завршува со проверка на извори и Human Gate.

A · Нов предмет

  1. Отвори CasePilot Space.
  2. Регистрирај документи и provenance.
  3. Направи timeline, claims/evidence и gaps.
  4. Отвори Fact Graph.
  5. Провери право/пракса преку Hybrid Research.
  6. Пушти Litigation/Evidence workflow преку Agents.
  7. Human Gate пред професионална употреба.

B · Договор

  1. Отвори Contract Intelligence.
  2. Залепи текст.
  3. Избери playbook clauses.
  4. Прегледај detected / not detected.
  5. За повеќе документи користи Review Tables.
  6. Contract Review agent подготвува review-ready белешки.
  7. Адвокат одлучува за позиција/редлајн.

C · Голем пакет документи

  1. Отвори Professional Tools → Batch Review.
  2. До 100 TXT/MD/CSV/JSON локално; PDF/DOCX преку Secure Workspace.
  3. Review Table → key terms / deadlines / references.
  4. Due Diligence workflow.
  5. Fact Graph ако има спорни факти.
  6. Deliverable Agent → memo/checklist.
  7. Human Gate.

D · Промена на закон/регулатива

  1. Отвори Current-Law Watch.
  2. Horizon Scanner споредува observations/versions.
  3. Candidate change ≠ current law.
  4. Authority Agent проверува извор, верзија и hierarchy.
  5. Regulatory Change workflow подготвува impact note.
  6. Human Gate пред употреба во совет/поднесок.

E · Правно истражување

  1. Почни во Hybrid Legal Intelligence.
  2. Провери закон, case law и ECHR ако е релевантно.
  3. Legal Research Memo workflow.
  4. Authority & Citation Agent проверува support.
  5. Adverse authority се проверува кај спор.
  6. Human Gate.

F · Повторлива задача / Proactive Agent

  1. Отвори Proactive Runtime и креирај Matter Space.
  2. Preview → Human approve → parallel dispatch.
  3. За custom spec отвори Agent Builder.
  4. Дефинирај objective, allowed capabilities и source boundary.
  5. Избери reusable workflow.
  6. Agentите работат паралелно каде е безбедно.
  7. Human Nudge кога е потребна адвокатска одлука.
  8. Scheduled run останува заклучен додека нема runtime authorization.

G · Каде ми е што?

  • Документи: Vault/Review Tables
  • Предмет: CasePilot Space
  • Право: Hybrid/Legal Base
  • Договор: Contract Intelligence
  • Факти/докази: Fact Graph
  • Промени: Horizon/Consolidator
  • Повторлива работа: Proactive Runtime → Agents/Agent Builder
  • Системска контрола: Command Center

H · Три правила

  1. Source-First: без извор нема правна сигурност.
  2. Candidate ≠ authority: нова информација прво се проверува.
  3. Human Gate: AI подготвува; адвокатот одлучува.
