# AI Advokat · ЗКП Quick Start v2.0

**Формула за добро прашање:** ФАЗА + СУБЈЕКТ + ШТО СЕ СЛУЧИЛО + ШТО САКАТЕ ДА ПОСТИГНЕТЕ.

## Што треба да добиете
1. Релевантен член/членови.
2. Законски слој — одвоен од коментарот.
3. Авторски коментар на Зоран Стојанкиќ.
4. Практична примена, ризици и поврзани членови.
5. Работна формулација кога е соодветно.
6. Јасна Human Gate напомена.

## Канонска хиерархија
Закон/официјален извор → судска практика → Коментар на ЗКП → практични водичи → AI синтеза → Human Gate.

## Важно
AI-помошта не ја заменува проверката на важечката верзија на законот, роковите, списите и професионалната проценка.
